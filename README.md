# HR Employee Attrition Analysis

## Project Overview
This project analyzes employee data to understand employee attrition and identify key factors associated with employees leaving the organization.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Charts
- Data Analysis

## Analysis
- Employee Attrition Rate
- Department-wise Attrition
- Age Group-wise Attrition
- Job Role-wise Attrition
- Education-wise Attrition
- Gender-wise Analysis
- Salary Band Analysis
- Job Satisfaction Analysis
